プライバシーポリシー

mellojoy-watch ／ 最終更新: 2026年10月21日

mellojoy-watch（以下「本アプリ」）は、作者個人が自分のために作成・利用している デスクトップアプリケーションです。本アプリは利用者の情報を収集するサーバーを持たず、 作者を含む第三者がデータを受け取ることはありません。

取り扱う情報

  • Google アカウントの情報（Gmail） — 本人認証コードのメールを読み取るために使用します。
  • 支払い情報 — 利用者本人が本アプリに入力したカード情報。
  • 動作ログ — 監視・購入処理の記録。

Gmail の利用範囲

本アプリは https://www.googleapis.com/auth/gmail.readonly のみを要求します。 メールの送信・変更・削除は行いません。

読み取るメールは、カード会社から届く本人認証コードのメールに限定しています。 具体的には、送信元アドレスと件名で絞り込んだうえで、認証コードの照合に必要な 項目（カード番号の下 4 桁・利用店名・金額・参照コード・認証コード）だけを取り出します。 それ以外のメールの内容は取得も保存もしません。

保存場所

取得した情報はすべて利用者自身のパソコンの中だけに保存されます。 外部のサーバーへ送信することはありません。

  • Google のアクセストークンとカード情報は、OS の暗号化機構 （Windows は DPAPI、macOS は Keychain）で暗号化して保存します。
  • 認証コードはその場で入力に使うだけで、保存しません。
  • 動作ログはローカルのファイルに保存され、一定期間を過ぎたものは削除されます。

第三者提供

本アプリは取得した情報を第三者に提供しません。広告・解析の仕組みも含んでいません。 通信先は、利用者が指定したストアおよび決済・認証に必要なサービス、 そして Gmail API のみです。

連携の解除

Google アカウントとの連携は、本アプリの設定画面から解除できます。 また Google アカウントのセキュリティ設定 からいつでも取り消せます。解除すると、保存されていたトークンは削除されます。

Google API Services ユーザーデータ ポリシー

本アプリによる Google API から取得した情報の利用は、 Google API Services User Data Policy （Limited Use requirements を含む）に準拠します。

お問い合わせ

本アプリは作者個人の利用に限られるため、一般向けの問い合わせ窓口は設けていません。 連絡先は Google Cloud プロジェクトに登録したデベロッパー連絡先のとおりです。
